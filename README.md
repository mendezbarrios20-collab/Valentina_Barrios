# 🌸 Valentina.Dev - Portafolio Profesional Interactivo

¡Bienvenido/a a mi repositorio! Este proyecto es mi portafolio personal, diseñado y desarrollado desde cero para mostrar mi perfil como **Desarrolladora Web Frontend**, mis habilidades técnicas, proyectos destacados y canales de contacto.

El sitio destaca por una interfaz moderna utilizando una paleta de colores en tonos pastel y una experiencia de usuario fluida y responsiva.

## 🚀 Características Técnicas & Requerimientos Cumplidos

### 🧱 HTML5 Semántico
- Estructura completamente limpia utilizando etiquetas semánticas estándares (`<header>`, `<main>`, `<section>`, `<footer>`).
- Uso correcto de jerarquías de texto (`<h1>`-`<h6>`), formularios accesibles e imágenes optimizadas.

### 🎨 CSS3 Avanzado (Layouts & Estilos)
- Maquetación responsiva basada en **Flexbox** y **CSS Grid** para una adaptación perfecta en móviles, tablets y pantallas de escritorio.
- Implementación de **Variables CSS (`:root`)** para una gestión de diseño y colores escalable.

### ⚡ JavaScript (ES6+) Interactivo & Manipulación del DOM
- **Menú Hamburguesa Animado:** Una experiencia fluida en dispositivos móviles donde el botón se transforma visualmente en una "X".
- **Filtrado de Proyectos Avanzado:** Sistema dinámico que utiliza métodos funcionales de arreglos (`.filter()` y `.forEach()`) para segmentar proyectos sin recargar la página.
- **Barras de Progreso Animadas:** Animación basada en eventos de scroll (`getBoundingClientRect`) y bucles modernos (`for...of`).
- **Validación en Tiempo Real:** Formulario robusto controlado con estructuras condicionales que asiste al usuario e informa errores instantáneamente en pantalla antes del envío.
